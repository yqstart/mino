# Mino 使用说明

## 快速上手

1. 启动 Mino：`cargo run`（或从 Release 安装 .dmg）
2. **本地终端**：启动即进入本地 shell（工作目录为 `$HOME`），直接使用
3. **连接远程主机**：`⌘N` 打开新建连接弹窗；或点标签栏 `>_` 快捷菜单，**单击**已保存主机即连；也可在「设置（⌘,）→ 主机管理」里**双击**主机行
4. 连接成功后：中央为远程终端；点终端右上角的悬浮 **SFTP** 按钮展开文件面板（可拖拽宽度，收起后右缘留拖拽把手）
5. **项目**：在本地标签里 `⌘D` 收藏当前目录为项目；`⌘O` 打开项目面板（搜索 + `↑↓` + 回车）即在新标签打开

## 快捷键

### 全局

| 快捷键 | 功能 |
|---|---|
| `⌘N` | 新建连接（弹窗） |
| `⌘T` | 新建本地终端标签 |
| `⌘O` | 项目面板（搜索 / `↑↓` 选择 / 回车打开） |
| `⌘D` | 收藏当前终端目录为项目 |
| `⌘W` | 关闭当前标签 |
| `⌘1` - `⌘9` | 切换到第 N 个标签 |
| `⌘,` | 打开 / 关闭设置（macOS 标准偏好设置键） |
| `⌘+`（含 `⌘=`）/ `⌘-` | 放大 / 缩小终端字号（步进 1pt） |
| `⌘0` | 终端字号恢复默认 13pt |
| `⌥1` - `⌥3` | 切换主题（深色 / 深蓝 / 霓虹） |
| `Esc` | 关闭前台弹窗；无弹窗时不拦截（保留给终端，如 Vim 退出插入模式） |

### 终端内

| 快捷键 / 操作 | 功能 |
|---|---|
| `⌘C`（或 `Ctrl+Shift+C`） | 复制选区（无选区时不向 shell 发送任何字符） |
| `⌘V` | 粘贴：文本直接写入；图片 / Finder 文件按路径插入（远程经 SFTP 中转，见下） |
| `Shift+PageUp` / `Shift+PageDown` | 回滚缓冲区（scrollback）翻页 |
| 拖入文件 / 目录 | 插入 shell 转义后的路径（不自动回车，可继续编辑命令） |
| 单击 OSC8 超链接 | 在浏览器打开（鼠标上报开启时让位给程序） |
| 滚轮 | 翻阅回滚缓冲区（程序开启鼠标上报时透传给程序） |

### SFTP 面板内

| 快捷键 / 操作 | 功能 |
|---|---|
| `⌘⇧L`（Windows/Linux 为 `Ctrl+Shift+L`） | 定位到当前终端目录 |
| 单击 | 选中条目；`Shift` / `⌘` / `Ctrl` + 单击多选（批量下载 / 删除） |
| 双击目录 / `..` | 进入目录 / 返回上级 |
| 右键 | 上下文菜单：打开目录 / 下载（选中项）/ 重命名 / 删除（选中项）/ 新建文件夹 / 上传文件 / 定位到当前终端目录 / 刷新 |

## 检查更新

- 启动后自动在后台检查 GitHub Releases 新版本（不阻塞、不弹窗打扰）
- 「设置」→「关于」→「检查更新」可手动触发；状态：新版本可用 / 已是最新 / 检查失败
- 发现新版后弹窗显示版本与更新说明，点「下载并安装」即在应用内下载（带进度），随后自动挂载 dmg、替换安装到「应用程序」并重启，无需浏览器

## 项目收藏

- `⌘D` 把**当前本地终端**的目录收藏为项目（远程标签不适用）
- `⌘O` 项目面板：输入即过滤，`↑↓` 选择，回车或单击在新标签打开；标签栏的文件夹图标是同一份收藏的快捷菜单
- 项目 = 名称 + 本地目录 + 可选启动命令（打开后自动执行一条命令）
- 「设置」→「项目管理」可新建 / 编辑 / 删除项目

## 主机管理

- 配置持久化于 `~/.config/mino/hosts.toml`（TOML，可手编；0600 权限、原子写入，损坏时自动备份为 `hosts.toml.bak` 并提示）
- 设置里**单击**条目选中、**双击**连接；行尾有删除按钮；标签栏 `>_` 快捷菜单**单击**即连
- 首次连接某主机时记录其 SSH 主机密钥指纹到 `~/.config/mino/known_hosts.toml`（TOFU）；之后密钥必须一致，不一致将拒绝连接并给出处理提示

## 远程终端

- 支持密码 / 私钥认证（私钥支持口令，路径可用 `~`）
- 远程 shell 与本地终端行为一致：彩色输出、滚动、粘贴、缩放（⌘+ / ⌘- 全局生效）
- 连接保活：30s keepalive，连续 3 次无响应判定断开
- 终端类型应答完整（颜色查询、焦点上报、kitty 键盘协议、鼠标上报、OSC8 链接、OSC52 剪贴板等）

## SFTP 面板

| 操作 | 方式 |
|---|---|
| 进入目录 | 单击选中，双击进入（目录名带 `/` 后缀） |
| 返回上级 | 双击列表首行 `..`（或右键 `..` 行 →「打开上级目录」） |
| 上传 | 右键 →「上传文件」，或多个文件用「上传文件」逐个选择 |
| 下载 | 选中条目（可多选）→ 右键 →「下载」/「下载选中项」 |
| 新建目录 | 右键 →「新建文件夹」 |
| 重命名 / 删除 | 选中单个 / 多个条目 → 右键；删除有确认对话框 |
| 定位终端目录 | `⌘⇧L`，或右键 →「定位到当前终端目录」 |
| 刷新 | 右键 →「刷新」，或标题行右缘按钮 |
| 传输进度 | 标题行右缘徽标：进行中 = accent2 圆底 + 进度弧环；全部完成 = 绿色对勾；有失败 = 红色感叹号。点击徽标展开 / 收起详情卡片；上传全部结束后可点「关闭」清理已完成记录 |

- 传输失败会清理半成品（下载删本地半成品、上传删远端半成品），不留截断文件
- 面板默认收起；展开占用窗口宽度的 40%（可拖拽，上限 50%）

## 图片与文件粘贴

- 拖 Finder 文件 / 目录 / 应用到终端区域：插入转义后的路径（不自动执行）
- `⌘V` 粘贴剪贴板图片或文件：本地终端直接写入路径；**远程终端会先经 SFTP 上传到远端**，再把远端路径写入命令行

## 主题

- 「设置」→「外观」切换三套主题：`深色`（默认，石墨绿）/ `深蓝` / `霓虹`
- 每套含独立终端调色板（16 色 + xterm 256 色表），切换即持久化到 `hosts.toml`，重启保持
- 快捷键 `⌥1` - `⌥3`

## 终端字号

- 「设置」→「外观」→「终端字号」滑杆（10–24pt，步进 0.5），或 `−` / `＋` 按钮与 `⌘+` / `⌘-` 微调（步进 1pt），「重置」回默认 13pt
- 字号全局生效（所有标签同时变），保存在 `hosts.toml` 的 `font_size` 字段，重启保持

## 常见问题

### 回车不执行命令

组字中（拼音候选窗打开时）回车被输入法消费（用于确认拼音候选），属于所有终端应用的共性行为：先选词上屏（再按一次回车执行），或切英文输入法（`⌃Space` 或 `CapsLock`）后回车。

### 中文输入法

终端完整支持中文输入法组字：拼音组字中时光标处内联显示预编辑串（下划线标出），选词后中文直接上屏写入终端，`Esc`/切输入法可取消未上屏的组字。

### 提示主机密钥已变化，连接被拒绝

服务器换了密钥、或中间人攻击。确认服务器更换过密钥后，删除 `~/.config/mino/known_hosts.toml` 中对应条目再重连（会重新记录新指纹）。

### macOS 提示"已损坏，无法打开"

产物未签名所致，执行 `xattr -cr "/Applications/Mino.app"` 后重新打开。

### 每次打开项目都问「是否允许访问文件夹」

这是 macOS 隐私保护（TCC）的正常行为：Mino 打开桌面/文稿/下载等位置的项目时，系统会弹窗确认。**点"允许"一次即可**，授权会记在该文件夹上。

如果**同一个文件夹每次都问**，几乎总是下面两种情形之一（先对照自查，再看根治）：

1. **Mino 刚更新过**：Mino 当前用 ad-hoc 签名打包，每次版本更新都会重新签名，系统会把之前授予的「文件和文件夹」授权清掉（Apple 对未使用 Developer ID 签名的应用就是这个行为）。更新后重新点一次"允许"即可。
2. **同时跑了两个 Mino**：比如一个在 `/Applications`、一个在 `target/debug` 或 `target/release` 里用 `cargo run` 启动——它们是**两个不同的应用身份**（CDHash 不同），授权不互通，换一个启动就问一次。认准只用安装版（`/Applications/Mino.app`）。

根治路径只有一条：改用 Apple Developer ID 签名 + 公证。签名身份稳定后，更新不再重置授权（除非大版本或系统隐私策略变化）。在此之前，每次更新后对常用项目目录重新点一次"允许"即可，无需删配置、无需重装。

### 终端字体 / 中文显示

终端字体为打包随附的 JetBrains Mono（Ghostty 等现代终端同款，0/O、l/1/I 区分明确），中文字体自动加载系统 PingFang / STHeiti，无需配置。
