# Mino 使用说明

> 版本基准：v2.0（Kaku 基准重构后）。功能定位见 [README](../README.md)。

## 快速上手

1. 启动 Mino：`cargo run`（或从 Release 安装 .dmg）
2. **本地终端**：启动即进入本地 shell（工作目录为 `$HOME`），直接使用
3. **连接远程主机**：`⌘N` 打开新建工作区弹窗（类型选「SSH 主机」）；或点标签栏「工作区」按钮，**单击**已保存的条目即开；也可在「设置（⌘,）→ 工作区」里**双击**条目
4. 连接成功后：中央为远程终端；点终端右上角的悬浮 **SFTP** 按钮展开文件面板（可拖拽宽度，收起后右缘留拖拽把手）
5. **收藏工作区**：`⌘B` 把当前会话存为工作区（本地标签→目录、远程标签→主机档案）；`⌘O` 打开工作区面板（搜索 + `↑↓` + 回车）即在新标签打开

## 核心概念：工作区

「工作区」是统一概念，两种类型同列表管理（存储在 `~/.config/mino/hosts.toml`，0600 权限、原子写入）：

- **本地目录**：名称 + 目录路径 + 可选启动命令
- **SSH 主机**：用户名、主机端口、认证（密码 / 私钥）、可选远端目录与启动命令

入口共三处：标签栏「工作区」按钮（快捷菜单）、`⌘O` 面板（搜索/回车打开）、设置弹窗「工作区」卡片（新建 / 编辑 / 删除）。

## 标签与分屏

- **标签标题**：本地标签显示「父目录/当前目录」（Kaku 语义）、远程标签显示主机名；多窗格以 `∙` 连接各窗格目录标签；双击标签标题可重命名；放大态窗格追加 ` [Z]`；窗口标题在多标签时带 `[i/n]` 前缀（Mission Control / 窗口菜单可见）
- **注意力点**：终端响铃（Bell）、命令失败（shell 集成退出码）、`OSC 9;4` 进度上报的出错/暂停，会在标签上点亮琥珀色圆点，切换过去即消除
- **分屏**：窗格间隙与 Kaku 同量级（约 5 个字宽，随字号换算）；焦点跟随点击；右键菜单同样提供拆分 / 关闭窗格

## SSH 远程终端

- 支持密码 / 私钥认证（私钥支持口令，路径可用 `~`）
- 远程 shell 与本地终端行为一致：彩色输出、滚动、粘贴、缩放（⌘+ / ⌘- 全局生效）
- 连接保活：30s keepalive，连续 3 次无响应判定断开
- 终端能力应答完整（颜色查询、焦点上报、kitty 键盘协议、鼠标上报、OSC8 链接、OSC52 剪贴板等），与本地终端共用同一套输入编码与渲染链路
- 首次连接某主机时记录其 SSH 主机密钥指纹到 `~/.config/mino/known_hosts.toml`（TOFU）；之后密钥必须一致，不一致将拒绝连接并给出处理提示

## SFTP 面板

| 操作 | 方式 |
|---|---|
| 进入目录 | 单击选中，双击进入（目录名带 `/` 后缀） |
| 返回上级 | 双击列表首行 `..`（或右键 `..` 行 →「打开上级目录」） |
| 上传 | 右键 →「上传文件」（逐个选择多个文件） |
| 下载 | 选中条目（可多选）→ 右键 →「下载」 |
| 新建目录 | 右键 →「新建文件夹」 |
| 重命名 / 删除 | 选中单个 / 多个条目 → 右键；删除有确认对话框 |
| 定位终端目录 | `⌘⇧L`，或右键 →「定位到当前终端目录」 |
| 刷新 | 右键 →「刷新」，或标题行右缘按钮 |
| 传输进度 | 标题行右缘徽标：进行中 = progress 弧环；全部完成 = 对勾；有失败 = 感叹号。点击徽标展开 / 收起详情卡片 |

- 传输失败会清理半成品（下载删本地半成品、上传删远端半成品），不留截断文件
- 面板默认收起；展开占用窗口宽度的 40%（可拖拽，上限 50%）

## 图片与文件粘贴

- 拖 Finder 文件 / 目录 / 应用到终端区域：插入转义后的路径（不自动执行）
- `⌘V` 粘贴剪贴板图片或文件：本地终端直接写入路径；**远程终端会先经 SFTP 上传到远端**，再把远端路径写入命令行

## AI 助手

当前版本（v2.0）的 AI 助手为 OpenAI 兼容的远程 API 形态：

- **生成命令**：命令行输入 `# 加上自然语言描述` 回车，AI 生成命令回填到提示符（不自动执行）
- **修复建议**：命令失败（非 0 退出码）后自动请求修复建议，收到后 `⌘⇧E` 填入提示符
- **聊天面板**：`⌘L` 打开流式聊天（自动带终端上下文：当前目录 + 最近可见输出），`Shift+Tab` 切换模型档位
- **配置**：「设置（⌘,）→ AI 助手」填写 API key，或把认证方式切为 `codex` 直接复用本机 Codex 登录态；配置写入 `~/.config/mino/assistant.toml`（0600）

> **规划中**：后续版本计划直接支持用户本机已安装的 Agent（pi、oh my pi（omp）、Claude Code、Codex CLI、opencode），详见 [README](../README.md#本地-agent规划中)。

## Shell 集成

首次运行会向 `~/.zshrc` 写入一段受管片段（幂等、首次备份、设置里可一键卸载）：

- 向终端上报提示符标记与工作目录（`OSC 133` / `OSC 7`）→ 权威当前目录、命令结束状态、失败修复建议触发
- 自动加载 zsh 增强：自动建议、语法高亮、补全、`z` 目录跳转、Smart Tab（三模式）、starship（可选）
- 相关插件由应用后台 `git clone` 到 `~/.config/mino/shell/vendor`，不影响其他终端

## 窗口快照

- 退出时自动保存标签布局（本地标签记目录、SSH 标签记主机档案）到 `snapshot.toml`（0600）
- `⌘⌥⇧T` 或命令面板恢复上次窗口（追加式恢复，不销毁当前会话）；窗口尺寸与位置也会记忆并在下次启动恢复

## 外观与字号

- 主题跟随 macOS 系统外观自动切换 Kaku Dark / Kaku Light（设置里可强制 `深色` / `浅色` / `自动`）
- 字号：设置滑杆（10–24pt）或 `⌘+` / `⌘-` / `⌘0`；全局生效、重启保持
- 窗口不透明度与（macOS）背景毛玻璃可在设置中调整；不透明度只作用于终端默认背景，显式着色的背景保持不透明

## 常见问题

### 回车不执行命令

组字中（拼音候选窗打开时）回车被输入法消费（用于确认拼音候选），属于所有终端应用的共性行为：先选词上屏（再按一次回车执行），或切英文输入法（`⌃Space` 或 `CapsLock`）后回车。

### 中文输入法

终端完整支持中文输入法组字：拼音组字中时光标处内联显示预编辑串（下划线标出），选词后中文直接上屏写入终端，`Esc`/切输入法可取消未上屏的组字。

### 提示主机密钥已变化，连接被拒绝

服务器换了密钥、或中间人攻击。确认服务器更换过密钥后，删除 `~/.config/mino/known_hosts.toml` 中对应条目再重连（会重新记录新指纹）。

### macOS 提示「已损坏，无法打开」

产物未签名所致，执行 `xattr -cr "/Applications/Mino.app"` 后重新打开。

### 每次打开项目都问「是否允许访问文件夹」

这是 macOS 隐私保护（TCC）的正常行为：Mino 打开桌面/文稿/下载等位置的项目时，系统会弹窗确认。**点「允许」一次即可**，授权会记在该文件夹上。

如果**同一个文件夹每次都问**，几乎总是下面两种情形之一（先对照自查，再看根治）：

1. **Mino 刚更新过**：Mino 当前用 ad-hoc 签名打包，每次版本更新都会重新签名，系统会把之前授予的「文件和文件夹」授权清掉（Apple 对未使用 Developer ID 签名的应用就是这个行为）。更新后重新点一次「允许」即可。
2. **同时跑了两个 Mino**：比如一个在 `/Applications`、一个在 `target/debug` 或 `target/release` 里用 `cargo run` 启动——它们是**两个不同的应用身份**（CDHash 不同），授权不互通，换一个启动就问一次。认准只用安装版（`/Applications/Mino.app`）。

根治路径只有一条：改用 Apple Developer ID 签名 + 公证。签名身份稳定后，更新不再重置授权。在此之前，每次更新后对常用项目目录重新点一次「允许」即可，无需删配置、无需重装。

### 终端字体 / 中文显示

终端字体为打包随附的 JetBrains Mono（三字重），中文字体自动加载系统 PingFang / STHeiti（后台加载，不阻塞启动），无需配置。

### 崩溃了怎么报

崩溃现场写入 `~/.config/mino/crash.log`（下次启动会提示并归档为 `crash.log.1`）。报告 Issue 时附上该文件。
