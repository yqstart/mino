# Mino 使用说明

## 快速上手

1. 启动 Mino：`cargo run`（或从 Release 安装）
2. **本地终端**：启动即进入本地 shell，直接使用
3. **连接远程主机**：按 `⌘N`，或打开标签栏「⚙ 设置」→「主机管理」→「新建连接」，填写主机 / 端口 / 用户名 / 认证方式
4. 连接成功后：中央为远程终端，点击右上角 **SFTP** 按钮展开面板（可拖拽调整宽度）

## 快捷键

| 快捷键 | 功能 |
|---|---|
| ⌘N | 新建连接 |
| ⌘T | 新建本地终端 |
| ⌘W | 关闭当前标签 |
| ⌘1 - ⌘9 | 切换标签 |
| ⌘, | 打开/关闭设置 |
| ⌘+ / ⌘- | 放大 / 缩小终端字号（10–24pt，自动保存） |
| ⌘0 | 终端字号恢复默认 13pt |
| ⌥1 - ⌥3 | 切换主题（深色 / 深蓝 / 霓虹） |

## 检查更新

- 启动后自动在后台检查 GitHub Releases 新版本
- 「设置」→「关于」→「检查更新」可手动触发；状态提示：新版本可用 / 已是最新 / 检查失败
- 发现新版后弹窗显示版本与更新说明，点击「下载并安装」即在应用内下载（进度条）并自动安装、重启

## 主机管理

- 配置持久化于 `~/.config/mino/hosts.toml`（TOML 格式，可手编）
- **单击**条目选中（左侧出现紫色指示条），**双击**直接连接
- 主机行单击选中、双击连接；行尾删除按钮移除主机。标签栏 `>_` 快捷入口中单击主机即可连接

## 远程终端

- 支持密码 / 私钥认证（私钥可带口令）
- 远程 shell 与本地终端行为一致：彩色输出、滚动（滚轮）、粘贴（⌘V，括号粘贴自动识别）

## SFTP 面板

| 操作 | 方式 |
|---|---|
| 进入目录 | 单击目录选中，普通双击进入（`目录名/` 显示） |
| 返回上级 | 双击列表首行 `..`，或在列表空白处右键选择「打开上级目录」 |
| 上传 / 新建目录 / 刷新 | 在列表行或空白处右键选择对应操作 |
| 下载 / 重命名 / 删除 | 选中条目后右键选择对应操作（删除有确认对话框） |
| 定位终端目录 | `⌘⇧L`，或右键选择「定位到当前终端目录」 |
| 传输进度 | 标题行右缘的状态徽标（进行中 / 全部完成 / 有失败三种形态）；点击徽标展开或收起详情卡片（进行中 / 完成 / 失败；上传全部结束后可点「关闭」清理记录） |

## 主题

- 「设置」→「外观」切换三套主题，每套包含独立终端调色板
- 快捷键 ⌥1-⌥3 快速切换

## 终端字号

- 「设置」→「外观」→「终端字号」滑杆拖动（10–24pt，步进 0.5），或 − / ＋ 微调、重置回默认
- 快捷键 ⌘+ / ⌘- 缩放、⌘0 重置；字号全局生效（所有标签同时变），保存在 `hosts.toml` 的 `font_size` 字段，重启保持

## 常见问题

### 回车不执行命令

组字中（拼音候选窗打开时）回车被输入法消费（用于确认拼音候选），属于所有终端应用的共性行为：先选词上屏（再按一次回车执行），或切英文输入法（`⌃Space` 或 `CapsLock`）后回车。

### 中文输入法

终端完整支持中文输入法组字：拼音组字中时光标处内联显示预编辑串（下划线标出），选词后中文直接上屏写入终端，`Esc`/切输入法可取消未上屏的组字。

### macOS 提示"已损坏，无法打开"

产物未签名所致，执行 `xattr -cr "/Applications/Mino.app"` 后重新打开。

### 每次打开项目都问「是否允许访问文件夹」

这是 macOS 隐私保护（TCC）的正常行为：Mino 打开桌面/文稿/下载等位置的项目时，系统会弹窗确认。**点"允许"一次即可**，授权会记在该文件夹上。

如果**同一个文件夹每次都问**，几乎总是下面两种情形之一（先对照自查，再看根治）：

1. **Mino 刚更新过**：Mino 当前用 ad-hoc 签名打包，每次版本更新都会重新签名，系统会把之前授予的「文件和文件夹」授权清掉（Apple 对未使用 Developer ID 签名的应用就是这个行为）。更新后重新点一次"允许"即可。
2. **同时跑了两个 Mino**：比如一个在 `/Applications`、一个在 `target/debug` 或 `target/release` 里用 `cargo run` 启动——它们是**两个不同的应用身份**（CDHash 不同），授权不互通，换一个启动就问一次。认准只用安装版（`/Applications/Mino.app`）。

根治路径只有一条：改用 Apple Developer ID 签名 + 公证。签名身份稳定后，更新不再重置授权（除非大版本或系统隐私策略变化）。在此之前，每次更新后对常用项目目录重新点一次"允许"即可，无需删配置、无需重装。

### 终端字体 / 中文显示

终端字体为打包随附的 JetBrains Mono（Ghostty 等现代终端同款，0/O、l/1/I 区分明确），中文字体自动加载系统 PingFang / STHeiti，无需配置。
